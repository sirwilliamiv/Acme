# Acme Home Ergonomics

Ergonomic support that HR teams can offer remote employees:

1. **Program**: HR sets a per-employee stipend. The page lists the credentials that qualify someone to assess a home workstation (CPE, CEAS, CRESp, COESp, licensed PT/OT).
2. **Find a professional**: a directory of firms that do in-home or virtual assessments, filterable by visit type and credential. It also links the official registries (BCPE, The Back School) for finding individual certified people near an employee.
3. **Assessment findings**: the assessor, or the employee as a self-screen, records issues such as neck strain or wrist pain.
4. **Marketplace**: equipment is flagged when it addresses a recorded finding. The cart tracks spend against the stipend and produces an order request for HR approval.

## Run

Open `index.html` in a browser. There is no build step or server. All data lives in `data.js`.

## Data notes

- Provider services are summarized from each provider's own website. Confirm coverage, credentials and pricing before contracting.
- Product prices are typical street prices. The example brands are suggestions, not affiliate listings.
